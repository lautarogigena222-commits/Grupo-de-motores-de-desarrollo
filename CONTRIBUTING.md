# Colaboración y registro de aportes

Este documento sirve para registrar evidencia real de trabajo grupal. **No atribuir tareas sin verificarlas.**

## Cómo colaborar

1. Crear una rama con nombre descriptivo (por ejemplo `feature/enemigos` o `fix/escena-hub`).
2. Realizar cambios pequeños y comprobables en Unity, conservando los archivos `.meta`.
3. Hacer commits descriptivos, por ejemplo `feat: agregar prefab del jefe Anubis`.
4. Abrir un pull request con resumen, capturas y pasos de prueba.
5. Solicitar revisión de otro integrante antes de fusionar.
